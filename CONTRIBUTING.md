# Contributing

BHAIRAV ENGINE is being developed as a structured methodology.

Contributions, discussions, examples and suggestions are welcome.

Before proposing changes to the core methodology:

1. Clearly identify the proposed change.
2. Explain the problem it addresses.
3. Distinguish new evidence from opinion or preference.
4. Preserve the terminology and structure of the methodology unless a change is intentional.
5. Do not represent modified versions as the official BHAIRAV ENGINE methodology.

Substantial modifications to the core methodology should clearly identify the contributor and the nature of the modification.
